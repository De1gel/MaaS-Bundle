## 检查方法及可支持的结论

| 检查 | 本次实现 | 结论边界 |
| --- | --- | --- |
| 原始可行性 | 用缓存 oracle 重新计算积分和全部 2,112 条选择约束，检查价格、allowance 边界 | 数值可行；不保证最优 |
| 完整一阶残差 | 非负最小二乘拟合乘子，另行计算可行性、归一化平衡残差、乘子符号和互补残差 | 所选 oracle 导数/次梯度下的一阶数值候选；不自动构成经典光滑 KKT 证明 |
| 响应一致性 | 同一菜单下重新计算乐观分配，比较 class 归属和真实利润 | 区分内层固定分配问题与完整乐观选择问题 |
| 导数与分支检查 | 三种有限差分步长、可行侧差分、平行活跃面、多个 envelope 交点、需求支持端点 | 识别不能直接使用 oracle Jacobian 做光滑二阶检验的位置 |
| 二阶曲率诊断 | 从当前积分 envelope 推导单分支解析 Hessian，并检查含临界锥的保守子空间 | 单分支正曲率只是诊断；在分支与导数适用条件未处理前不颁发 SOSC 证书 |
| 邻域改进探测 | 20 个 allowance 坐标方向加 4 个随机方向，分别用固定分配下的价格 LP 优化，重查全部原约束 | 找到可行改进是继续搜索的证据；没有找到不证明局部最优 |
| 缩小扰动路径 | 对观察到的上升方向，连续缩小到相对半径 1e-7 | 稳定正上升率是数值上升路径证据；有限次计算不是数学上的任意小邻域证明 |

没有计算全局上界或全局 gap，因此不作全局最优声明。

这里的改进是相对于**同菜单重新计算的乐观利润**，不是相对于较低的旧固定 assignment 利润。路径上的原始选择约束最大违反量不超过 1.71e-13。

半径采用相对无穷范数：每个坐标以 `max(1, abs(candidate_coordinate))` 为尺度。单个有限距离的更优点不能自动否定某个更小邻域内的局部最优；本次缩小路径给出了继续上升的数值证据，而非形式化反证。

### 历史最佳完整候选

该菜单利润重算仍为 17.567399878424993，乐观响应一致，有 10 个 traveler cost ties、没有 double tie。在相对半径 1e-4 和 1e-2 内，各完成 22 次有效探测，总计 44 次，没有发现更高利润。

它目前应标记为：**通过原始可行性与选定次梯度下一阶检查、未在本次局部探测中发现改善的候选点**。这不等价于局部或全局最优证书。

## 为什么现在不直接颁发 SOSC 证书

四个点均有 allowance 在零下界或非常接近零下界。oracle 返回的是允许的凸次梯度，它在下界处不一定等于可行侧的单侧导数。实际观测到：

- 历史最佳点某个活跃约束中，basic car-sharing allowance 为 0。oracle 给出的相应导数为约 -0.770467，可行侧差分稳定在约 -0.273733；两者差约 0.496734。
- 该点用原 oracle Jacobian 再差分估计 Hessian 时，相对步长从 1e-3 降到 1e-5，和当前解析分支的差异从约 42 增大到约 4221。不能把该差分矩阵当成真实的光滑拉格朗日 Hessian。
- 正向可行方向的导数可加性误差随步长降低而趋零。因此，不能仅凭并列面标志就断言在可行域上不存在光滑延拓；必须区分域外不光滑、可行侧导数、以及 oracle 次梯度选择。

当前单分支的保守投影 Hessian 对四个菜单都呈正特征值；历史最佳点最小值约 1.09e-4。但这个数值不能跳过上述导数一致性、活跃面和真实临界锥问题，所以本报告不将它称为通过经典 SOSC。

另外，历史最佳点按现有选定法向量计算，有 13 条活跃条件，数值秩为 6。活跃约束存在依赖，不能默认 LICQ 或仅对全部活跃法向量的零空间做未经说明的特征值检验。SOSC 的充分性本身不要求在已经存在 KKT 乘子的基础上再额外满足 LICQ，但相关必要性或简化公式必须核对各自条件。

正确的后续二阶验收顺序是：确定可行侧一致的局部表示及导数，核验乘子，构造真实临界锥，再检查其上的真实拉格朗日二阶曲率。当前数据只支持数值诊断。
