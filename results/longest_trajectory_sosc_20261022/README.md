# 最长区域切换路径的逐次 NLP SOSC 检查

日期：2026-10-22。

对象：start 85，14 个区域、13 次切换、41 次受限 NLP 调用、44 次底层 SLSQP 尝试。

**结论：本次没有任何返回点获得经典 SOSC 的数值确认。** 这是适用条件未确认或前置检查未通过，不等于证明这些点均非局部最优。

## 数值判定规则

- 当次受限 NLP 可行性阈值 `1e-7`；归一化一阶平衡阈值 `1e-5`；绝对互补残差阈值 `1e-6`。乘子由非负最小二乘拟合。
- 活跃集以 `1e-4` 建立，另用 `1e-8`、`1e-6` 检查敏感性。
- 每个返回点同时检查完整固定 assignment 区域的全部旅客约束。受限 NLP 的 SOSC 即使成立，也只有在该点对完整区域可行时才可转移。
- 用当前积分 envelope 构造真实单分支的解析 Hessian，不使用 SLSQP 的 BFGS 矩阵。成本为原实例的线性 allowance 成本。
- 二阶方向使用正乘子约束法向量的零空间，它包含所选乘子对应的临界锥。零乘子活跃不等式没有被强行当作等式。因此在该较大子空间上正定是保守曲率支持，不通过则不能直接否定真实临界锥上的 SOSC。
- 对非线性坐标使用相对步长 `1e-3`、`1e-4`、`1e-5` 检查导数及 Hessian，下界附近使用单侧公式。平行活跃面、多重交点和支持端点被单独标记。
- 只有可行性、一阶、互补性、导数/分支、活跃集和曲率的检查全部通过，才报告数值 SOSC 支持；仍不当作区间算术意义的严格证明。

## 最后一次 NLP 的具体结果

第 41 次调用，区域 14；固定分配利润 `15.323380503977` USD/代表性加权旅客/月。
原区域违反量 `3.555e-10`，归一化一阶平衡残差 `1.946e-06`，互补残差 `6.271e-09`。

该点 premium bike allowance 在零下界。其相关活跃约束的 oracle 次梯度与可行侧差分导数的最大差异约 `0.006757`，步长降低后仍存在。直接对原 oracle Jacobian 再差分时，和单分支解析 Hessian 的误差从约 `0.654` 增长至 `65.52`。这不能当作已获得真实光滑 Hessian。

并列面的存在本身不是对可行域不存在光滑延拓的证明。本次结论仅是：当前 oracle 次梯度、单分支 Hessian 与完整经典 SOSC 的适用条件尚未建立一致性，因而不颁发经典 SOSC 确认。
